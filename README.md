# Abhinash Panigrahi - Dynamic .NET Developer Portfolio

A modern, dynamic, and interactive React portfolio website built for **Abhinash Panigrahi** (.NET Developer with 1 year experience), inspired by the **"Portrait in Dots"** 3D WebGL aesthetic.

---

## ✨ Features

- **🔴 3D Particle Bust Hero Section (WebGL / Three.js)**:
  - ~5,000 interactive particles dynamically shaped into a 3D bust silhouette (head, neck, shoulders)
  - Dark crimson particle styling (`#dc143c`) with additive blending
  - **Cursor Tracking**: Interactive mouse-reactive rotation with smooth easing
  - **Atmospheric Effects**: Drifting background dust particles, film grain overlay, radial vignette, and light sweep animation
  - ** Anton Font Watermark**: Faded `DEVELOPER` background typography
  - Typing animation cycling through roles: *.NET Developer*, *Backend Engineer*, *Full Stack Developer*

- **🧭 Sleek Navigation**:
  - Glassmorphic fixed navigation bar with blur effect
  - Active section indicator with animated underline
  - Responsive mobile drawer navigation

- **👤 About Me**:
  - Highlights your 1+ years of experience, completed projects, and technical strengths
  - Dynamic AP monogram with animated pulsing rings

- **⚡ Tech Skills Grid**:
  - **Backend**: C#, ASP.NET Core, Entity Framework
  - **Database**: MS SQL Server, PostgreSQL
  - **Frontend**: HTML5, CSS3, JavaScript, jQuery, Bootstrap, AJAX
  - **Tools**: Git, Visual Studio, VS Code, Postman
  - Interactive cards with hover glow and animated progress bars

- **💼 Experience Timeline**:
  - Interactive vertical timeline highlighting your work as a .NET Developer
  - Responsive layout for mobile and desktop

- **🚀 Featured Projects**:
  - Employee Management System (ASP.NET Core, SQL Server, Bootstrap)
  - E-Commerce REST API (ASP.NET Core, PostgreSQL, JWT Auth)
  - Task Tracker Dashboard (AJAX, jQuery, Bootstrap)
  - Portfolio Website (React, Three.js, Framer Motion)

- **📬 Contact Section**:
  - Interactive contact form with floating labels
  - Direct contact cards (Email, Location, LinkedIn)

- **📦 Standalone Build Included**:
  - Single zero-dependency `portfolio-standalone.html` file that opens directly with a double-click in any browser!

---

## 🚀 Getting Started

### Development Server
```bash
npm install
npm run dev
```
Preview link: **http://localhost:5173/**

### Production Build
```bash
npm run build
```

### Standalone File
Double-click `portfolio-standalone.html` in the root folder to view the full portfolio offline in any browser without running a server!
